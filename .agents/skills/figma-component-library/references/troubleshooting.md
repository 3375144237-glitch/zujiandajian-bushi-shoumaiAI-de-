# Figma 组件难点：定位、修复、复验与预防

先在获授权的副本复现，再修改最小范围。用相同测试复验原问题，并回查共享引用和邻项。

## 1. 浮层、描边或阴影看错

- **定位：** 打开整张画板，查同级帧、绝对定位层和覆盖层；按可见文字、绝对坐标和叠放匹配触发器与面板。分别读两者的填充、描边厚度（保留小数）、描边对齐、效果和定位。边缘与读数不同时，逐级查 Clip content、兄弟层遮挡与描边是否参与布局。
- **修复与复验：** 用正确图层做定稿对照；复用原生描边，避免额外分隔形状占掉布局高度。仅在需要的位置调整裁切或叠放。导出含阴影的完整区域，量间距，检查可见边缘及邻项。
- **下次：** 触发器、展开面板和浮层宿主分开记录，留整张画板作基线。

## 2. 颜色偏差，或背景透明度影响到内容

- **定位：** 检查 Paint 是否可见、Paint Alpha、节点及父层透明度，再读颜色变量别名和生效模式。隐藏的填充仍可能有颜色值。
- **修复与复验：** 只让背景变淡时用对应语义的带 Alpha 填充；整颗组件变淡才设根层透明度。变量覆盖 Paint Alpha 时调整授权范围内的绑定，避免更改共享原始色。切实际模式，读回后同底色导出比较。
- **下次：** 盘点时记录用途、模式、别名和透明度所在层级；批改前先验一个真实实例。

## 3. 字体、字重或文字读回正常，导出却不对

- **定位：** 比较原稿和实例的字体、数值字重、行高、文案、文本框和实例覆写。测试当前编辑环境能否实际加载字体；同名样式或正确字符不代表渲染正确。
- **修复与复验：** 能加载原字体时，在独立副本刷新问题文字并恢复正确内容，保留文本属性绑定；必要时用能加载字体的桌面环境。若有同内容同字重且正确渲染的文字层，可在副本复用并重连绑定。分别导出母版、实例和同倍率定稿，逐层核对字形和数值；无法验证时标待核。
- **下次：** 批写前试改一条长文案和各代表字重并导出，确认工具的写入与渲染都正常。
- **桌面批量改字后有色偏：** 回读字重与各文本段填充；若插件的临时高亮留在实例，仅恢复误改的颜色，保留合法覆写和母版变量绑定。再次同底色导出。

## 4. 切换变体后丢失文字、图标或 Slot

- **定位：** 在实例先覆写再切换，读取各变体对应子层的类型、层级、属性键与绑定。检查 Boolean 是否绑对包裹层、交换属性是否接到实际嵌套实例、Slot 是否退化为普通 Frame。
- **修复与复验：** 对应子层重新绑定组件集的同一属性。环境支持 Slot 时，从原生变体核对并恢复实际绑定，包括适用的 `slotContentId`。业务可编辑文字与状态专属文字分别管理。用新旧实例做 A → B → A，核对覆写、显隐、位置和母版链接。
- **下次：** 加一个变体就先跑切换测试，再批量复制；保留母版节点 ID 和属性键。
- **合并或重排组件集后：** 读回实际 `defaultVariant` 和重建后的属性键。同一个 Text 属性可影响整个集合的默认值。占位和已选值独立编辑时分别绑定；状态决定的文案留在对应变体。新插默认档并做往返切换，分别查默认占位、已选值和覆写。

## 5. Fill 列不等宽，或缩放后文字错位

- **定位：** 沿子层向上看每一轴的 Fixed、Hug、Fill，量最小宽度、文本模式、内边距和兄弟层占宽。比较同宽的新实例与缩放过的旧实例，区分母版结构错误和已有几何覆写。
- **修复与复验：** 等宽内容用结构一致的列容器；从母版创建新实例，先设置目标宿主宽度，再覆写文本。逐行核对列起点、换行、截断和邻层坐标，分别导出原宽、窄宽和长文字。
- **下次：** 用不同宽的业务父框测试，不能让 Fill 把所有对照撑成同宽。先验证布局，再批量覆写内容。
- **交互切换时控件跳动：** 检查焦点描边是否被计入自动布局；用不参与布局的描边或焦点环。加载指示不新增排版占位，保持可编辑动作名。展开箭头用同一图标区，按旋转后的边界核对视觉中心和对齐。逐状态读回母版与实例宽高、图标位置和邻项坐标。

## 6. 新增内容后重叠，或父框裁掉底部

- **定位：** 逐级检查父框实际高度、最后子层底边、底距和 Clip content。确认下一组是否独立定位；有 Hug 标记也可能保留旧高度。阴影超出外框不等于实体重叠。
- **修复与复验：** 移除多余固定尺寸和占位；旧高度未刷新时，从最内层按子项、间距和内距逐层更新尺寸，再恢复各轴应有的尺寸策略。自由摆放的兄弟区块按实际边界重排。导出修改组和邻组，并在副本增删内容确认能回流；父框的 Hug 标记或顶层无重叠不足以证明内层正常。
- **下次：** 同类预览放到同一个父级自动布局；新增状态或长说明后回查相邻区块。

## 7. 修改波及定稿，或工具只写入一部分

- **定位：** 动手前查母版消费者、嵌套子实例、样式和变量别名。超时后逐一重读目标节点 ID、父级、属性及绑定，识别已写、未写、写错的范围。
- **修复与复验：** 有未知引用时在隔离副本用独立资产，确认不共享待改资源。只补未完成项；误写只恢复本次改变的节点，保留他人修改。以代表实例和定稿基线复核。
- **下次：** 按小批保存目标 ID、旧值和执行结果，写后先读回。预览合并或移动后实际打开原有链接，失效时按内容定位正确目标。
